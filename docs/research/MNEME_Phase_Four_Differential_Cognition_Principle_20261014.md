# MNEME Phase Four: Differential Cognition as the Influence Criterion

This research principle guides tests of the transport mechanism between a history-shaped associative neighborhood and a frozen host model. It does not by itself authorize production integration or supersede the governing Phase Four safety, competence, compatibility, and reversibility requirements.

The defining influence question is whether holding the host and present input fixed while changing only the accessible associative structure produces a corresponding, attributable difference in what becomes salient and how the host reasons. A meaningful result is bank-specific: different neighborhoods should produce distinguishable reasoning tendencies, while no-bank and irrelevant-bank controls should not reproduce the same directional pattern.

Factual retrieval and task-performance benchmarks remain useful diagnostics. They are not substitutes for this criterion. A changed output, increased attention mass, or a single matching phrase is not sufficient evidence. Evaluation should preserve the reasoning and final answer, include matched controls and repeated contexts, and recognize transformed expression rather than requiring literal repetition of the bank.

This criterion describes observable influence on model behavior. It does not establish consciousness, human-like memory, personality, or general developmental success. The tested neighborhood may be synthetic and controlled; later work is required to determine whether real developmental history produces similarly attributable influence.
