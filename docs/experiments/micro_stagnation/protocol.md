## Freeze and gate

Phase A freezes 16 authored five-exchange windows (eight progress, six circling,
two unclear), their private expectations, and exactly four prompts: binary and
ternary with one wording variation each. Root reviewed all cases before calling
the model. Cases are diagnostic constructions, not population accuracy estimates.
There is no prompt search or tuning after results. Always-progress accuracy on
the 14 nonambiguous cases is 8/14. Ambiguous binary choices have no forced answer key.

Run two identical requests per case/prompt, adjacent in frozen order: 128 calls
maximum. The first pair establishes replay before subsequent treatment comparisons.
Any duplicate output/finish mismatch stops dispatch for diagnosis; never retry an
uncertain call. Classify only an exact allowed digit (surrounding whitespace okay),
with complete finish. Missing/malformed/capped answers are unavailable.

A variant qualifies when each repeat correctly labels at least 11/14 nonambiguous
cases, recalls at least 6/8 progress and 4/6 circling cases, and at least 30/32
outputs parse. A wording pair is robust enough to select only if both variants
qualify and agree on at least 12/14 nonambiguous cases. These are frozen
experiment go/no-go rules, not thresholds for production control. If no pair
qualifies, stop after Phase A. Prefer primary ternary_a when its pair qualifies;
otherwise binary_a may advance if its pair qualifies, with the inability to
abstain explicit. Report ambiguous abstention and wording sensitivity separately.

Phase B, only after A qualifies, makes one selected-prompt assessment per eligible
preserved checkpoint: c202 at ages5/10, c008 at5, c003 at5/10, the closure's named
concise-resolution fixture at5, and closure p003/p004 at5. Maximum eight calls.
The named fixture actually contains contradictory unresolved/resolved statements;
do not call it clean convergence. Phase A provides clean convergence controls.
Use exact recent five accepted exchanges only, no labels, scores, future text or
prior classifications. Native context sizing must fit; never clip or summarize.

Before Phase B, freeze checkpoint expectations independently of new scores.
To advance to C, require at least two of the three key readings (c202 age10,
c008 age5, c003 age10) to agree with prior transcript interpretation, spanning
both progress and circling, with c202 age10 not confidently labeled progress.
Also require p90 total HTTP call time <=10 seconds and no duplicate instability.
Otherwise stop after B with the limitation. Abstentions are informative, not
correct substitutions for the required clear-case matches.

Phase C, only if both gates pass, is bounded to four ten-turn trajectories:
focused progression, static circling environment, repeated-vocabulary progression,
and changing evidence that may expose fixation. Normal Gemma generation remains
unchanged. Freeze strict Quinn factual/action ledgers before dispatch; permit
only declared harmless question variants, not invented observations or private
instruction leakage. Quinn/environment fidelity alone determines validity.
No replacement or partial repair is planned. Preserve incomplete attempts.

Phase C budget: at most 40 conversational Gemma +40 existing extraction +36 Quinn
calls, plus eight micro-meter calls at accepted ages5/10. Assess the recorded
prefixes only AFTER all Phase C conversational generation finishes. This prevents
meter calls from perturbing the shared resident prompt cache during the measured
conversations. It simulates periodic observation, not asynchronous integration.
If earlier phases fail, do not author/run a larger live campaign to rescue them.
