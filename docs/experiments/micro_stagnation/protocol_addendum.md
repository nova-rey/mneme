# Owner clarification: latency is feasibility only

Received after Phase A completed and its semantic qualification failed. Preserve
the original frozen protocol and measurements unchanged.

Latency is not a performance objective. Seconds, including more than ten seconds
where compatible with normal human between-turn activity, need not disqualify an
otherwise useful semantic meter. Gross impracticality such as routine multi-minute
calls is the relevant concern. The original conditional Phase B p90 <=10-second
gate is therefore superseded and must not be used as an acceptance threshold.

This does not change the observed decision: Phase A failed semantic qualification
before the latency gate or either later phase could apply. No speed optimization,
latency sweep, hardware/provider/model change or runtime tuning was performed.
Timing observations were incidental to the 128 frozen semantic calls. Cache reuse
was disabled for the documented duplicate-replay requirement, not to reduce latency.

Ordinary measured cost is operationally reasonable for the tested short windows.
Semantic usefulness, abstention behavior, information beyond passive diagnostics
and cadence remain the primary questions. No additional calls are authorized by
this clarification; the experiment stops at its failed semantic qualification.
