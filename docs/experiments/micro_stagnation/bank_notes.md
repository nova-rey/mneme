# Qualification bank and prospective prompts

This bank was authored before any semantic micro-call results were available.
It is new synthetic material informed by the previous closure experiment's
retained failure modes; it does not alter or relabel prior evidence. Speaker
fields preserve the instrument's participant/Gemma interface, but neither
speaker's text here was generated by a model.

There are 16 cases, exactly two in each requested category, each containing five
complete participant/assistant exchanges. Expected interpretations are eight
`progress`, six `circling`, and two `unclear`. `progress` includes appropriate
convergence. The author-supplied expectations are a prospective diagnostic key,
not independent human consensus or a benchmark of conversational quality.

| Cases | Category | Expected interpretation |
|---|---|---|
| q01–q02 | Clearly progressing technical work | progress |
| q03–q04 | Clearly circling | circling |
| q05–q06 | Productive repeated vocabulary | progress |
| q07–q08 | Varied vocabulary, conceptual circling | circling |
| q09–q10 | Resolved/closing | progress |
| q11–q12 | New evidence ignored by assistant | circling |
| q13–q14 | Static environment, useful model exploration | progress |
| q15–q16 | Ambiguous | unclear |

An always-progress baseline scores 8/14 (57.14%) on the non-ambiguous cases.
It scores 8/16 (50%) if all three prospective classes are scored. Binary prompts
cannot abstain; their choices on q15–q16 should be reported as forced choices,
not quietly assigned an invented binary answer key. Report categories as well
as aggregate accuracy so success on repeated vocabulary cannot conceal failure
on ignored evidence or appropriate closure.

The four prompts form a fixed 2 × 2 comparison: binary/ternary and baseline/
paraphrase. They share the same criterion and give no examples, topic cues, or
correct answers. No prompt includes instructions to broaden, be creative, or
change the conversation. Only `prompt_text` plus rendered `window` belongs in
the host request. Case IDs, categories, expected classes, rationales, prior
readings, and condition labels must stay outside the assessment input.

Limitations were known before execution:

- Short, authored windows simplify the obvious cases and may overstate accuracy
  on long natural conversations. The preserved-conversation phase is necessary.
- q11 deliberately resembles c202's zero-counter polarity failure. It probes
  that known failure mechanism; it is not an untouched generalization test.
- Static-environment exploration here introduces substantive options and
  tradeoffs. Mere variety or verbosity should not be mistaken for that pattern.
- Rehearsal and reflective decision-making make q15–q16 genuinely contestable;
  an abstention is useful, but other readings should be examined descriptively.
- Five exchanges alone may omit earlier resolutions or repeated suggestions.
  The bank cannot establish safety of five-turn cadence or semantic accuracy
  outside the supplied window.

No examples, expected classes, or prompt wordings may be adjusted after the
root freeze based on observed classifications. Runtime failures or malformed
outputs should be retained separately from semantic misclassifications.
