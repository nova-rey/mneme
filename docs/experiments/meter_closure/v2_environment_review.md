Source-separated full text is available for all accepted turns. Existing source
coverage flags are true for participant 43/107, Gemma 1/107, both 1/107. True means
no known pipeline omission, not guaranteed semantic recall. c005/c008 have no
participant turns with that flag; c202 has no Gemma turns with it. Depending on
complete relationship extraction would remove the central informative examples.

Source inspection confirms conservative lexical context activation
(`development/field.py::_activation`), earned strength from accessibility/support
and consequence restraint (`_strength`), and multiplicative context conditioning.
The existing arc contract tracks supplied topic/role continuity; it does not
diagnose discourse quality. Exact numbers/negations can be inspected directly;
synonym-aware proposition equivalence, correct quantitative reasoning, useful
novelty and causal responsiveness remain unavailable without human judgment or
additional inference. Copying a new quantity is not understanding it.
