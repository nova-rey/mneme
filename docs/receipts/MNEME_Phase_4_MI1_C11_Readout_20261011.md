# MI1 C11 selected-site readout diagnostic

C11 did not make the bank's structured rules usable to Gemma. It did establish that the selected-bank path is active: selected query heads put substantial attention on the 81 appended bank slots, and later hidden query states measurably change. Yet selected-bank answers remained `unknown`, exactly as Gemma reasoned when no-bank controls were present. This is a negative diagnostic, not a final MI1 disposition; the owner has authorized continued local investigation.

The 144 unique frozen coordinates comprise eight held-out rule fixtures, two seeds, and nine conditions. One original attempt ended with an empty client stream despite server-side completion; it remains preserved as lost evidence. A separate frozen recovery journal reissued that one coordinate and ran the 119 untouched coordinates. The recovered matrix has 144 complete unique outputs. Total campaign inference is 792 calls, including the preceding 647 calibration calls.

Under the unchanged answer-plus-complete-path rubric, no-bank scored 16/16 unknown; selected A and B each scored 0/16; old sparse and random controls each scored 0/16; visible A scored 11/16 and visible B 12/16. Thus the selected bank did not beat the controls, and the visible control itself fell short of the frozen 80% gate. A parser correction now recognizes common Markdown answer forms; the corrected rates above are lower-bound exact rubric results, not a changed rubric.

The prefill-only diagnostic compared the exact same 707-byte model-visible prompt with no bank and with selected-A attached. The selected bank's expected fingerprint was verified. At the final prompt token, mean bank attention mass was 0.448 across the 16 selected query heads and zero at unselected heads (0.02135 averaged over all 336 heads). The query-state RMS difference was zero at the first selected layer 7, then 0.0151 at layer 31, 0.0400 at layer 34, 0.0503 at layer 38, and 0.0575 at layer 41. No tokens were generated during this capture. This proves a routed computational effect, not semantic memory use.

On A05 selected-A, Gemma's recorded reasoning says that no background rule record is present, notes that the visible prompt contains no activation rules, and answers `unknown`. C11 therefore rules out a missing attachment, empty bank, or absent selected-head mask as the explanation for this coordinate. It does not yet distinguish whether Gemma needs a stronger generic readout cue, different bank construction/accessibility, or a more fundamental semantic-readout correction.

Earlier diagnostics are consistent: C6–C9 latent conditions also failed to retrieve the relation; C10 tried raw-plus-context and contextualized bank variants, with 0/8 target retrieval; C11 changed selection sites using held-out-independent query alignment, again without retrieval. The prior “8/8” result was the visible-text positive control, not latent-memory success. In the frozen Test A, latent A and B each scored 0/24; no-bank and irrelevant-bank controls each scored 23/24 unknown. Test B shows prose perturbation, but the sampled correct-bank tool-lending responses remain ordinary tracking/check-out designs without a defensible bank-derived timing/availability structure. Test C's fresh-bank, replacement, ongoing-bank, and restoration answers did not recover their expected paths. These are separate evidence streams and are not collapsed into C11's numerical rubric.

Next, a new calibration will freeze an explicit but content-free side-memory availability cue and a bounded selected-site logit-bias sweep on new fixtures. It will retain no-bank, visible, irrelevant-bank, and latent conditions, and use separate held-out confirmation only if a frozen calibration rule passes. The bank contents themselves will not enter the ordinary prompt. The new calibration is motivated by the demonstrated gap between attention routing and semantic retrieval; it does not assume that increasing bank attention will fix it.
