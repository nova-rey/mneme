## Responsibility boundary

The specialist scores source-window/hypothesis pairs. Deterministic MNEME code
owns source availability, lossless bounded windowing, score aggregation,
coverage decisions, exact source evidence binding, correspondence bookkeeping,
and serialization into the existing `p2-assessor-v6` semantic contract.
No provenance labels, developmental credit, offsets, or learner state are
generated by the specialist.

Long sources are processed through deterministic overlapping character windows;
the adapter selects the strongest window per source with deterministic
tie-breaking. Missing required source slots produce `unknown`, and no source is
silently truncated into complete coverage.
